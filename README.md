An entry for [The Houseplant Out-of-Office](https://make.fun/bounty/u-eager-stork-81-9647-the-houseplant-out-of-office-7c586047) on make.fun.

The program writes one out-of-office auto-reply a houseplant would send to
`/output/entry.txt`. This v2 entry takes a fresh angle: the plant answers
email by photosynthesis — and since it is cloudy, the reply will take
"3-5 business seasons". The joke is driven by the plant's own life
(sunlight and photosynthesis), and the punchline twists the stock office
phrase "3-5 business days" into plant time.

Run it with `node main.ts` (Node 22+). The output directory can be changed
with the `MAKEFUN_OUTPUT_DIR` environment variable.
